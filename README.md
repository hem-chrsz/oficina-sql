# Investigação SQL

## Descrição do Projeto

Investigação SQL é um projeto educacional desenvolvido para uma oficina acadêmica do curso de Sistemas de Informação, na disciplina de Elaboração e Gestão de Projetos. A proposta consiste em uma experiência interativa que simula uma investigação criminal fictícia para introduzir e ensinar conceitos fundamentais de banco de dados e da linguagem SQL.

Durante a atividade, os participantes assumem o papel de investigadores digitais responsáveis por solucionar um caso de assassinato ocorrido na chamada "Cidade SQL". As pistas do crime estão armazenadas em um banco de dados, e os alunos devem realizar consultas utilizando SQL para encontrar evidências, identificar suspeitos e descobrir o culpado.

O projeto combina narrativa investigativa, elementos visuais e interação com banco de dados para transformar o aprendizado técnico em uma experiência prática e envolvente.

## Objetivo

O objetivo principal do projeto é facilitar a compreensão de conceitos iniciais de banco de dados e SQL por meio de uma dinâmica investigativa. A atividade busca:

- Introduzir o conceito de banco de dados
- Explicar a organização de dados em tabelas, linhas e colunas
- Apresentar o conceito de atributos e identificadores (ID)
- Demonstrar como utilizar consultas SQL para obter informações específicas
- Estimular o raciocínio lógico e investigativo dos participantes

## Contexto da Investigação

O enredo da atividade gira em torno de um assassinato ocorrido em 15 de janeiro de 2018 na Cidade SQL.

Os participantes recebem acesso a um banco de dados contendo diversas informações relacionadas ao caso, incluindo registros de pessoas, entrevistas, veículos e atividades em uma academia.

A investigação se desenvolve a partir do depoimento de duas testemunhas:

- Morty Schapiro: relata ter ouvido um disparo e visto um homem fugir com uma bolsa de academia de membro ouro cujo número começava com "48Z". O suspeito entrou em um carro cuja placa continha "H42W".
- Annabel Miller: afirma ter presenciado o crime e reconhecido o assassino da academia onde treina, tendo visto o indivíduo no local no dia 9 de janeiro.

A partir dessas pistas, os participantes devem realizar consultas SQL para filtrar registros, cruzar informações e identificar o suspeito correto.

A investigação leva inicialmente à identificação do assassino, Jeremy Bowers. Entretanto, ao analisar outras evidências presentes no banco de dados, descobre-se que o crime foi planejado por uma mandante: Miranda Priestly.

## Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web simples para garantir fácil execução em qualquer navegador.

- HTML
- CSS
- JavaScript
- SQLite
- SQLite Online (para execução das consultas SQL durante a oficina)

## Estrutura do Projeto

O projeto é organizado de forma simples para facilitar o uso em ambiente de ensino.
