🗄️ O que é um Banco de Dados?

📊

Banco de Dados

É um sistema organizado para armazenar, gerenciar e recuperar informações. Pense nele como um arquivo digital gigante e inteligente.

📋

Tabelas

Os dados são organizados em tabelas, como planilhas. Cada tabela guarda um tipo de informação (pessoas, crimes, pistas...).

↔️

Linhas e Colunas

Cada linha é um registro (ex: uma pessoa). Cada coluna é um atributo (ex: nome, idade, endereço).

🏷️

Atributos

São as características de cada dado: nome, data, local, tipo... Eles nos ajudam a filtrar e encontrar pistas!

Exemplo de Tabela: testemunhas

💻 Como acessar as pistas?

"O banco de dados guarda as pistas."

"Mas como conversar com ele?"

SQL

Structured Query Language

A linguagem que usamos para consultar o banco de dados e encontrar as pistas.

SELECT

Escolhe quais colunas você quer ver.

SELECT nome, idade
FROM

Indica de qual tabela buscar os dados.

FROM testemunhas
WHERE

Filtra os dados com uma condição.

WHERE idade > 30

Consulta completa:

SELECT nome, idade
FROM testemunhas
WHERE idade > 30;
